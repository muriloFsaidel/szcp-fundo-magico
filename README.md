## Semana do Zero ao Programador Contratado

  <p>O projeto foi concebido a partir da conclusão da semana do Zero ao Programador Contratado da escola Dev em Dobro e ministrado pelo professores Beto e Cadu.<br/>
     Conteúdo da semana teve como objetivo construir uma aplicação front-end HTML, CSS e Javascript para fazer requisições a API do N8N, nesta requisição o usuário descreve um background/fundo de uma determinada cor para outra e o Agente de IA com prompt disponibilizado pelos professores, consegue consultar o google gemini para trazer o código HTML e CSS para preencher cartões de texto e aplicar o fundo descrito pelo usuário. Além do aprendizado de construir uma página HTML e CSS passo a passo, este projeto permite utilizar a automação N8N para construir o fundo dinamicamente usando IA como serviço.
   </p>
   <br/>
   <p>
    Github de referência da do Zero ao Programador Contratado Dev em Dobro: https://github.com/devemdobro/fundo-magico-szpc
   </p>
   
  ## Conceitos
  
 - Estrutura HTML
 - Elementos, objetos, métodos, funções, estrutura condicional, tratamento de exeções com try catch e finally, eventos, requisições para API usando fetch, variáveis (let,var e const) e atributos
 - Manipulação de estilos CSS utilizando seletores por tag, classe, descendência, id e global, responsividade (@media)
 - Utilização de IA como ferramenta de aprendizado e resolução de dúvidas
 - Ferramenta de automação N8N por meio de configuração de webhooks, e AI Model
 - Github pages deploy
